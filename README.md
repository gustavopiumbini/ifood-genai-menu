# 🍔 Menu Mágico: Gen AI para Delivery

> Projeto desenvolvido visando otimizar a conversão de vendas de pequenos restaurantes no iFood através de descrições geradas por Inteligência Artificial.

## O Problema
Pequenos empreendedores muitas vezes têm pratos incríveis, mas não sabem vender no texto. Descrições fracas diminuem a conversão.

## A Solução
Uma aplicação web que utiliza lógica de Engenharia de Prompt (simulada neste MVP) para criar textos de marketing com gatilhos mentais específicos (Gourmet, Divertido ou Vendedor).

## Tecnologias
- **Python & Streamlit**: Para interface e lógica ágil.
- **Arquitetura Modular**: Separação de responsabilidades (Front-end, Lógica e Estilos).
- **UX/UI**: Design System focado na identidade visual do iFood.

## Como rodar
pip install -r requirements.txt
streamlit run app.py
